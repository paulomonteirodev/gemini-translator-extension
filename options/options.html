Tradutor com IA – para Gemini

Cada pessoa usa a sua própria chave de API do Gemini.

1. Crie sua chave gratuita

  1. Acesse o Google AI Studio e entre com sua conta Google.
  2. Clique em Create API key (Criar chave de API).
  3. Copie a chave e cole abaixo.

2. Cadastre a chave

Modelos “Flash” são rápidos e têm limites gratuitos maiores. Recomendado para tradução.

Privacidade

A chave fica salva apenas neste navegador e só é enviada para a API do Google (generativelanguage.googleapis.com). Ela nunca é compartilhada com os sites que você traduz.

No plano gratuito, o Google pode usar o texto enviado para melhorar os produtos dele. Evite traduzir páginas com informações sensíveis.
